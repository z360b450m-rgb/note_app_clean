# 对话后台执行与异常快照

主聊天由 App 提供 `createReviewAgentChats`，单题对话由 App 提供 `createEntryLearningConversations`。组件关闭或切换只解绑视图，不中断已经提交的对话。主聊天可切换会话并分别等待回复；单题结果写回发起请求的题目和会话，不会显示到另一道题。后台任务入口可打开原对话。

存储按登录账号隔离。发送、流式增量、状态变化使用同步持久化；完成、异常、重试和页面退出额外保存检查点。异常保留已生成内容，并把错误单独显示。重试前保留上一份回复快照。打开题目时直接恢复最近一轮记录。

`beforeunload` 保存标记为中断的副本；若用户取消离开，不会误停当前请求。`pagehide` 终止浏览器中的连接并保存中断状态。若浏览器意外退出，最近收到的增量已保存在主记录中；再次加载时把残留的运行状态改成可重试的异常。主记录损坏时尝试读取完整检查点。

对题目内容只保存短指纹，兼容旧版正文指纹，不再把嵌入图片的完整正文复制到聊天存储。编辑题目或主动清空会中断相应请求，避免旧内容的回复覆盖新会话。

验证：`tests/e2e/test_chat_background_snapshots.py` 覆盖面板卸载、题目与聊天切换、后台完成、异常部分回复、重试快照、关闭并重开浏览器页面、损坏主记录恢复；`test_review_insight_card.py` 覆盖单题界面、历史、停止、会话、账号隔离及同步后恢复；`test_agent_chat_title.py` 验证三轮命名保持兼容。浏览器测试需要 Vite，默认5174端口。
