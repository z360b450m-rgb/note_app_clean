# 智能错题本技术框架

系统采用前后端分离架构，同时支持浏览器和 Electron 桌面端。围绕错题管理、复习学习与知识库组织功能，通过独立的 RAG 服务提供 AI 复习助手能力。

![技术框架图](technical-framework.svg)

| 层级 | 主要内容 | 技术框架与实现方向 |
| --- | --- | --- |
| 展示层 | 错题编辑、复习工作台、知识库、学习统计等用户界面 | Vue 3 + TypeScript；Electron 提供桌面端，浏览器提供 Web 端 |
| 接口层 | 前后端数据交互、用户认证、AI 回答流式传输 | FastAPI 提供 REST API；JWT 认证；SSE 实时展示助手回答 |
| 业务层 | 账号管理、错题管理、复习学习、知识库管理、AI 复习助手、词汇学习 | 按功能模块组织业务，界面与业务状态通过 Vue Composables 协作 |
| 应用层 | 笔记本与分类管理、复习记录与统计、导入导出、错题检索与排序、知识库入库、AI 会话管理 | 组合业务流程，通过服务接口协调本地数据、后端和外部 RAG 服务 |
| 组件层 | 编辑工具、菜单与动效、文档解析、公式与 Markdown 渲染、插件面板 | Tailwind CSS、Reka UI、Motion / GSAP、PDF.js、KaTeX、markdown-it；SQL.js 支持浏览器侧词库导入 |
| 基础服务层 | 数据访问、本地存储、离线同步、文件与图片处理、插件扩展、AI 服务适配 | Repository 存储接口、SQLAlchemy、Electron 文件接口、浏览器存储、独立 RAG 服务接入 |
| 数据源 | 账号与学习数据、本地缓存、图片与文档、备份与词库文件 | MySQL、IndexedDB / localStorage、桌面本地文件，以及 PDF、Markdown、JSON、APKG 等资料 |

身份认证、账号数据隔离、日志记录和异常处理贯穿各层。前端统一维护界面风格和交互动效，业务模块共享基础服务与数据访问能力。

AI 复习助手经本项目后端接入独立的 `shopkeeper_brain` 查询服务；图中的 RAG 能力表示外部服务接入，不限定该服务内部的模型或向量数据库实现。

## 主要流程

- 编辑器的题目、公共材料和答案各自管理富文本选区。图片工具按当前编辑区分派操作，公式使用 KaTeX 预览并持久化 LaTeX 源码。菜单、确认框和选择器使用共享组件，保存状态在题目标题区反馈。
- 前端维护复习队列。业务后端将题目 ID 与作答交给查询服务核对，并在事务中写入已判定结果及计数。继续追问复用单题学习对话。[智能判卷接口](review-grading-api.md)
- 关联组题通过查询服务检索候选，再由业务后端验证归属、正文版本和引文。用户确认签名预览后，前端按确认顺序开始练习。[关联组题接口](related-review-bundle.md)
- 学习资料可独立导入知识库。源错题在手动执行入库后更新索引。[学习资料导入接口](knowledge-document-import.md)
