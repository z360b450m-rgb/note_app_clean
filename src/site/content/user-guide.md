# ReNote 使用指南

## 使用指南概述 {#overview}

### 文档内容

ReNote（错题集）用于整理错题、记录作答和安排复习。本指南介绍现有功能的操作方法。

首次使用时，请阅读[快速上手](#quick-start)。批量录入试卷时，请阅读[导入题目](#importing)。需要知识点讲解时，请阅读[AI（人工智能）学习助手](#assistant)。

| 要完成的操作 | 对应章节 |
| --- | --- |
| 将一批题目从文件夹 A 移到文件夹 B | [文件夹与题目移动](#folders) |
| 将手机照片或截图转换为可编辑文字 | [照片与截图转文字](#image-text) |
| 给多道题添加标签，找回筛选后消失的题目 | [分类、搜索与批量操作](#classification) |
| 调整图片宽度，标记条件，关联另一道题 | [录入与图文编辑](#editing) |
| 修正 PDF 选项，调整材料与小题的归属 | [导入题目](#importing) |

本指南的截图来自网页版应用。编辑和题组截图使用“设计展示”示例。局部图中的编号与图下说明对应。单击截图可放大，按 **Esc** 关闭大图。

窗口宽度变化时，工具位置可能随布局调整。查找图标按钮时，可将鼠标移到按钮上查看名称。

### 使用条件

网页版通过浏览器访问。桌面版另提供桌面截图、本地数据目录和原生文件操作。

登录、PDF（便携式文档格式）解析、知识库检索和智能判卷需要连接对应服务。使用前，请确认网络连接和服务状态正常。

## 快速上手 {#quick-start}

### 登录与创建错题本

在官网单击 **进入网页版**，使用邮箱和密码登录。首次使用时，可切换到注册页面，填写邮箱后单击 **发送验证码**，输入邮件中的 6 位验证码。验证码 10 分钟内有效，60 秒后可重新发送。密码需要 8–128 位，两次输入须一致。

忘记密码时，在登录页单击 **忘记密码？**，通过邮箱验证码设置新密码。登录后也可以在 **设置 → 账号 → 修改密码** 中，输入当前密码和新密码完成修改。修改或重置密码后，所有设备都需要重新登录。

在应用首页单击 **新建错题本**，填写名称和简介。例如，名称可以填写“英语语法”。创建后，单击错题本名称进入工作区。

:::figure home

### 录入错题

单击 **新建错题**，分别填写题目、错误答案和正确答案。在答案区域记录解题思路，再选择学科、来源和标签。

例如，虚拟语气题可以记录以下内容：错误答案为 **have**，正确答案为 **had**。错因是将假设情境理解为真实情况。

### 保存与复习

按 **Ctrl + S** 保存。开启自动保存后，应用会在停止输入后保存修改。

单击 **进入复习**，选择题目并作答。提交时，填写答案和关键理由。完成后，可查看[统计与学习记录](#statistics)。需要进一步讲解时，可使用[AI 学习助手](#assistant)。

> 首页的“开始复习”打开学习助手。错题本工具栏的“进入复习”打开答题练习。

## 管理错题本 {#notebooks}

### 创建、编辑和排序

首页和左侧列表均提供 **新建错题本** 入口。首页列表显示名称、题数、复习进度、更新时间和标签。单击编辑按钮，可修改名称和简介。

在首页侧边栏拖动错题本名称，可调整展示顺序。单击工作区左上角的 **返回**，可回到首页并切换错题本。

### 首页的数量与进度

首页显示错题本数量、总题数和今日复习进度。列表中的“完成/需复习”用于查看当日进度。

显示“—”时，表示对应统计尚未读取。出现读取失败提示时，单击 **重新读取统计**。仍可打开已加载的错题本。

### 查看复习计划

在首页侧边栏单击 **复习计划**。可查看今日完成率、待复习题数、近 7 天复习分布和学科分布。

在 **今日复习安排** 中，单击对应错题本的 **打开**，进入该错题本。首页的 **开始复习** 进入学习助手。

**学习报告** 当前显示“功能即将上线”。查看已提供的统计时，请进入错题本并单击 **统计**。

### 选择整理方式

| 整理方式 | 用途 | 说明 |
| --- | --- | --- |
| 错题本 | 区分考试、学科或学习阶段 | 从首页创建与切换 |
| 文件夹 | 在一本错题本中分区存放题目 | 参见[文件夹与题目移动](#folders) |
| 学科 | 标记题目的所属学科 | 每题选择一个学科 |
| 来源 | 记录试卷或教材出处 | 每题选择一个来源 |
| 标签 | 标记知识点或错因 | 每题可选择多个标签 |

分类和批量整理方法见[分类、搜索与批量操作](#classification)。删除错题本前，可先[导出归档](#backup)。

## 文件夹与题目移动 {#folders}

### 新建、展开与收起文件夹

1. 打开需要整理的错题本。
2. 在左侧题目列表上方，单击 **新建文件夹** 图标。
3. 输入名称，按 **Enter** 或单击 **创建**。
4. 单击文件夹名称或左侧箭头，展开或收起题目列表。

按 **Esc** 可取消新建。文件夹属于当前错题本，同一本中的文件夹平级排列。未设置文件夹的题目显示在 **未归档** 下。

选中文件夹后再新建错题，新题会放入该文件夹。先选中 **未归档** 再新建，可创建未归档题目。

:::figure folder-overview

### 将题目移入另一个文件夹

1. 展开原文件夹，勾选需要移动的题目。
2. 核对列表上方显示的 **已选** 数量。
3. 将鼠标移到目标文件夹所在行。
4. 单击该行的向下箭头按钮，完成移动。
5. 展开目标文件夹，确认题目已经移入。

箭头按钮仅在选中题目后出现，鼠标移到文件夹行上时显示。按钮提示包含已选题数和目标文件夹名称。

移动后，应用会取消本次选择。题目内容、答案和已有学习记录随题目保留。

:::figure folder-move

### 将一个文件夹的全部题目迁移到另一个文件夹

例如，将“待整理”中的题目全部移到“专题练习”：

1. 清空搜索，并恢复学科、标签和来源的 **全部** 范围。
2. 取消掌握程度筛选，避免遗漏被隐藏的题目。
3. 打开 **已选** 菜单，选择 **取消选择**。
4. 展开“待整理”，逐一勾选其中的题目。
5. 题目连续排列时，也可先勾第一题，再按住 **Shift** 勾最后一题。
6. 确认 **已选** 数量与原文件夹题数一致。
7. 将鼠标移到“专题练习”行，单击移入按钮。
8. 检查原文件夹数量变为 0，再展开目标文件夹核对。

:::figure folder-result

> 顶部的 **全选题目** 会选中所有符合当前筛选条件的题目。即使其他文件夹已收起，其中的题目仍可能被选中。仅移动一个文件夹时，请在该文件夹内选择题目。

文件夹显示的数量也受筛选影响。迁移全部内容前，请先恢复完整列表。题目拖动用于[自定义排序](#classification)，跨文件夹移动请使用移入按钮。

### 移回未归档

先勾选题目，再将鼠标移到 **未归档** 行。单击 **将已选错题移到未归档**，可清除这些题目的文件夹归属。

### 重命名与删除文件夹

将鼠标移到文件夹行，单击铅笔图标，输入新名称。按 **Enter** 或单击其他位置保存，按 **Esc** 取消。文件夹内题目的归属会同步更新。

单击垃圾桶图标后，按钮提示变为 **再次点击确认删除**。再次单击才会删除文件夹。原有题目会移到 **未归档**。

需要删除题目本身时，应选择题目并执行[批量删除](#classification)。

## 分类、搜索与批量操作 {#classification}

### 创建学科、来源与标签

左侧筛选区的 **学科**、**标签**、**来源** 标题旁均有新建按钮。创建后，可在题目上方的对应控件中选择。

新建时，勾选 **应用于所有错题本**，可将名称加入通用分类。不勾选时，名称仅加入当前错题本。此设置用于提供分类选项，已有题目仍需分别选择分类。

学科和来源各选一项。打开下拉菜单，选择顶部占位项，可清除当前值。标签支持多选，可同时标记“方程”“计算错误”等内容。

### 给当前题目添加或移除标签

1. 单击题目上方的 **标签**。
2. 输入关键词，查找已有标签。
3. 单击标签，切换选中状态。
4. 未找到所需名称时，单击 **创建**，或按 **Enter** 新建。
5. 在顶部已选标签旁单击 **×**，可从当前题目移除该标签。

从题目移除标签后，标签名称仍可用于其他题目。完成分类后，按 **Ctrl + S** 保存。

:::figure tags

### 重命名、删除分类与快捷新建

将鼠标移到左侧分类项，单击 **⋯**。可重命名或删除该项。学科项还提供 **新建错题**，用于创建已选定学科的题目。

重命名时，按 **Enter** 或单击对勾保存，按 **Esc** 取消。删除时，先核对名称与关联题数，再单击对勾确认；单击 **×** 可取消。

重命名分类时，当前错题本中相关题目的值会同步修改。删除学科后，题目归入 **未分类**。删除来源后，题目的来源清空。删除标签后，仅移除该标签。

### 组合筛选与恢复完整列表

左侧学科、标签、来源和掌握程度可以组合使用。结果须同时符合各类条件。例如，选择“数学”和“计算错误”，可查找相应错题。

单击各分类的 **全部**，可恢复对应范围。再次单击已选掌握程度，可取消该条件。再清空工作区搜索框，恢复完整列表。

文件夹展开状态只控制列表展示。找不到题目时，请同时检查筛选条件、搜索词和文件夹是否展开。

### 搜索题目及答案

在工作区顶部的 **搜索错题** 中输入关键词。搜索范围包括题目名称、题干、答案、学科、来源、标签和题组公共材料。

搜索与左侧筛选同时生效。清空搜索词后，其他筛选仍会保留。全文搜索不可用或不完整时，页面会显示提示；可恢复连接后重试。

### 排序与修改题目名称

单击题目列表上方的排序按钮，可按更新时间、创建时间、学科或标题排列。再次选择当前排序项，可切换升序与降序。选择 **乱序**，可重新打乱顺序。

选择 **自定义** 后，可拖动题目调整同一列表内的先后顺序。

双击列表中的题目名称，可直接重命名。按 **Enter** 或单击其他位置保存，按 **Esc** 取消。名称修改不替代题干编辑。

### 多选与取消选择

| 操作 | 作用 |
| --- | --- |
| 勾选题目左侧方框 | 添加或取消一题 |
| Ctrl + 单击题目行 | 添加或取消一题，保留其他选择 |
| 先选一题，再 Shift + 单击另一题 | 选择同一展开列表内的连续范围 |
| 顶部全选框 | 选择全部符合筛选条件的题目，包含收起的文件夹 |
| 已选菜单 → 取消选择 | 清空所有已选题目 |

批量操作前，核对 **已选 N** 数量。没有选择时，按钮显示 **共 N 条**。需要整理某个文件夹时，按[文件夹迁移步骤](#folders)选择范围。

### 批量标签、导出与删除

勾选题目后，单击数量按钮，打开批量操作菜单。

- **批量标签**：向所选题目添加标签。
- **批量导出**：下载所选题目的 JSON（数据交换格式）文件。
- **批量删除**：按确认提示删除所选题目。

添加批量标签时，先在标签选择框中选好名称，再单击 **确认**。单击 **取消**，可放弃本次标签操作。

批量导出适合提取部分题目。跨设备完整迁移时，使用[导出归档](#backup)。文件夹移动按钮位于目标文件夹行上。

## 录入与图文编辑 {#editing}

### 编辑题目与答案

在题目区域填写完整题干和选项。在错误答案区域记录原作答，在正确答案区域填写标准答案和解题思路。使用显示或隐藏按钮，控制答案区域的展示状态。

:::figure editor

### 确认格式工具作用的位置

先单击需要编辑的区域，再使用顶部格式工具。工具栏左侧会显示 **题目**、**公共材料**、**错误答案** 或 **正确答案**。

选中文字时，格式应用于所选内容。未选中文字时，加粗或荧光设置用于后续输入。可先确认区域名称，再修改格式。

### 加粗与荧光颜色

单击 **B** 或按 **Ctrl + B**，可切换加粗。选择内容包含多种加粗状态时，按钮会提示混合状态。

荧光笔分为主按钮和右侧下拉箭头。主按钮使用最近选择的颜色；下拉箭头打开调色菜单。选择 **无颜色**，可清除所选内容的荧光。

若显示 **混合**，表示所选文字含多种荧光格式。此时单击主按钮，可统一为当前颜色。

:::figure formatting

### 调整图片显示大小

先单击正文中的图片，再打开 **调整图片大小**。可选择原始尺寸或 25%、50%、75%、100%。未选中图片时，该控件不可用。

调整宽度用于控制图片在编辑区中的显示。将照片识别为文字的方法见[照片与截图转文字](#image-text)。

### 添加、打开与取消题目链接

1. 在当前编辑区选中一段文字。
2. 单击 **链接到其他题目**。
3. 搜索题目名称、科目、来源或标签。
4. 单击目标题目，将其关联到所选文字。

未选择文字时，会在光标位置插入目标题目名称。再次单击正文中的链接，会打开关联窗口。

在关联窗口单击 **打开题目**，可跳转到目标题。单击 **取消链接**，可保留文字并移除关联。选择其他题目，可更换链接目标。

目标题目已删除时，关联窗口会显示相应提示。可取消失效链接，或重新关联已有题目。

:::figure question-link

### 使用画笔批注

单击工作区工具栏的 **画笔**，进入手绘模式。使用画笔标注条件或图形，使用橡皮擦除笔迹。

在画笔模式下，按 **Ctrl + Z** 撤销，按 **Ctrl + Y** 重做。需要继续输入文字时，关闭画笔模式，再单击编辑区。

### 保存与布局调整

自动保存开关位于[设置](#settings)中。关闭自动保存后，请按 **Ctrl + S** 保存修改。

切换题目时，应用会检查未保存的修改。可按提示选择保存、不保存或取消切换。

单击 **调整布局**，出现板块拖动手柄和分隔线。拖动手柄可交换位置，拖动分隔线可调整宽度或高度。

单击 **完成布局** 后锁定排列。需要还原时，先进入布局调整，再单击 **恢复默认**。

**收起答案** 可将更多空间留给题目。单击 **展开答案** 恢复答案区域。各答案标题旁的 **显示/隐藏** 控制对应内容。

:::figure layout

## 照片与截图转文字 {#image-text}

### 选择图片要插入的区域

先打开一道题，单击需要插入内容的位置。图片可以放入题目、公共材料、错误答案或正确答案区域。

顶部工具栏显示当前区域名称。确认名称后，单击 **导入图片**；也可直接在编辑区粘贴剪贴板图片，或拖入图片文件。

| 图片入口 | 操作方法 |
| --- | --- |
| 已保存的照片 | 单击导入图片，选择图片文件 |
| 剪贴板截图 | 先用系统截图，再在目标编辑区按 Ctrl + V |
| 拍照 | 单击拍照，允许摄像头权限后拍摄 |
| 拖入文件 | 将图片文件拖到目标编辑区 |

网页版可使用系统截图后粘贴。桌面版另提供桌面截图入口。

### 裁剪需要识别的内容

题目和公共材料中的照片导入后，会先进入裁剪界面。

1. 拖动选框，将题干或需要的内容放入框内。
2. 拖动四角，可改变选框大小。
3. 拖动选框内部，可移动识别范围。
4. 确认范围后，单击确认按钮，进入文字识别。

按 **Enter** 可确认裁剪。单击 **跳过裁剪** 或按 **Esc**，会使用整张图片继续识别。单击 **返回** 则取消此次处理。

错误答案和正确答案区域导入图片后，会直接进入 **图片转文字** 窗口。已完成截图选区的图片也会直接识别。

:::figure image-crop

### 校对识别文字

**图片转文字** 窗口会自动开始识别。左侧显示原图，右侧显示 **识别文字（可修改）**。

1. 等待识别完成，右侧文本框恢复可编辑状态。
2. 对照原图，核对题号、选项、数字与公式。
3. 直接修改识别错字，补充缺失内容。
4. 单击 **插入文字**，将结果放入开始操作时的光标位置。
5. 返回编辑区，继续排版并按 **Ctrl + S** 保存。

例如，原图中的 `x + 3 = 7` 应保留加号与等号。再核对选项字母和“参考答案：C”，避免答案与选项错位。

:::figure image-text

### 只要文字、图文并存或仅插图片

| 需要的结果 | 操作 |
| --- | --- |
| 可编辑文字 | 核对结果，单击插入文字 |
| 文字和原图 | 勾选同时保留原图，再单击插入文字 |
| 保持图片形式 | 单击仅插入图片 |
| 放弃本次导入 | 单击取消或关闭按钮 |

图表、几何图和复杂公式可勾选 **同时保留原图**，供后续核对。**跳过裁剪** 仍会识别文字；**仅插入图片** 才会直接插图。

### 旋转、重新识别与失败处理

在原图右上角单击左转或右转按钮，每次旋转 90°。旋转后会清空当前结果并重新识别。需要保留手动修改时，应先复制已修改的文字。

单击 **重新识别**，可重新处理当前图片。新结果会替换文本框内容。

无文字、识别失败或超时时，可重新选择更清晰的图片。也可使用 **仅插入图片**，先保存原图，再手动录入。

识别期间，**插入文字** 暂不可用。选择 **仅插入图片** 可结束等待并插图。切换到其他题目会结束当前图片处理，请先完成插入或取消。

已作为图片插入的内容不会自动变成文字。需要转换时，可再次导入原图，并在识别窗口选择 **插入文字**。

## 题组与公共材料 {#question-groups}

### 适用场景

题组适用于同一份材料对应多个小题的场景，例如阅读理解和资料分析。各小题共用公共材料，分别保存答案和复习记录。

### 创建题组与小题

在普通题目的编辑区域单击 **转为题组**，按提示确认。将共用文字、图表或图片放入公共材料区域。小题区域填写当前小题的内容。

:::figure group-create

单击 **添加小题** 增加题目。使用 **上一小题** 和 **下一小题** 切换。各小题的错误答案和正确答案分别保存。

:::figure question-groups

### 区分公共材料与当前小题

多题共用的文章、表格和图形放在公共材料区。仅当前题使用的设问或选项放在小题区。修改公共材料后，同组其他小题也会使用新内容。

工具栏会显示当前编辑区域。先单击公共材料，再导入图片，可将图片或识别文字放入材料。先单击小题，则插入当前题干。

左侧列表中的 `1.(1)`、`1.(2)` 等编号用于识别同组小题。复习时，各小题分别作答，共用材料会随题显示。

### 核对导入结果

PDF 解析完成后，先检查各题是否依赖同一份材料，再确认题组归属。可调整已有题组归属。拆组时，请保留公共材料。小题独有的图片应保留在对应题目中。

> 题组归属以是否共用材料为依据。同页或同知识点仅作为核对线索。

## 导入题目 {#importing}

### 导入 PDF 试卷

1. 进入目标错题本，选择 **更多 → 导入 PDF**。
2. 选择试卷并提交解析。可等待处理完成，或按提示转入后台。
3. 核对题干、选项、图片、公共材料、题组和原文答案。
4. 修正解析结果，勾选需要的题目，再确认入库。

PDF 解析需要登录，并连接对应服务。原文缺少的答案、作答和解析会保留为空，录入后可手动补充。

### 在目录中选择需要的题目

校对窗口左侧显示题目目录与公共材料目录。单击题号，定位右侧编辑区。使用复选框选择需要入库的题目；目录顶部的全选框用于切换整份草稿的选择。

题号旁出现待核对标记时，先查看该题提示。确认导入时发现的问题会列在顶部，单击问题可直接定位。

### 校对题干、题型和选项

右侧可直接修改题干，并选择 **选择题** 或 **非选择题**。文字选项可修改字母和内容，单击 **×** 移除多余项，使用 **补充选项** 添加缺项。

图形选项保留在题目原图中时，按图中字母作答。无需为了通过校对而编造文字选项。

展开 **答案与作答**，可补充参考答案、解析和原作答。原文件未提供的内容可以留空。

### 校对公共材料与拆分题组

单击 **查看并校对关联材料**，或选择左侧材料目录，可修改材料标题和正文。材料编辑区还列出关联小题，单击题号可返回。

在小题的公共材料选择框中，可更换材料归属。选择 **独立题（保留已有材料）**，可拆出小题并保留原材料内容。

拆分后，应核对保留的文字和图片。再次归组前，也应检查是否存在重复材料。

### 对照原文件与确认保存

单击 **查看原 PDF**，打开原文件。按原页逐项核对图片、跨页题干、选项和答案。

核对所选题数后，确认导入。看到 **题目已导入** 和保存题数后，关闭窗口并在错题本中查看。

### 导入文本

选择 **更多 → 导入文本**，粘贴题目内容。建议使用 `1.`、`2)` 或 `（3）` 等题号。选择题使用 `A.`、`B.` 等选项标记，并填写“答案：B”。

设置统一的学科、来源和标签。核对底部的识别题数，再单击 **一键导入**。本页截图包含 2 道选择题，预览显示识别出 2 题。

可按以下格式准备文本：

```text
1. 若 x + 3 = 7，则 x 的值是（ ）。
A. 2
B. 4
C. 7
D. 10
答案：B
解析：等式两边同时减去 3，得到 x = 4。

2. 下列哪一种复习方式更有助于发现知识盲点？
A. 直接抄写标准答案
B. 独立作答后核对理由
答案：B
```

:::figure importing

### 查看后台任务

处理时间较长时，可按提示转入后台。任务中心显示进度、处理结果和失败原因，并提供返回任务的入口。任务取消或失败后，请按提示重新处理原文件。

**后台运行** 会保留处理任务。需要终止时，应使用任务提供的取消操作。返回校对窗口后，再核对所选题目与当前状态。

### 选择导入位置

需要作答并记录复习结果的试题，导入错题本。需要保留全文并用于检索的讲义，导入[知识库](#knowledge)。

## 复习与智能核对 {#reviewing}

### 选择复习范围

在错题本工具栏单击 **进入复习**。选择 **到期复习**，练习已经到期的题目。选择 **自由练习**，从全部题目中选择。

可多选学科和标签，并设置随机顺序和本轮题数。到期题数为 0 时，可选择自由练习。

:::figure review-setup

### 填写答案与理由

应用识别出可点选的选择题时，可直接选择选项。其他题目在 **我的作答** 中填写答案。建议同时说明关键条件、计算步骤或理由。

本页示例可填写：**B. had**。该句表示与现在事实相反的假设。if 从句使用一般过去时，主句使用 would 加动词原形。

:::figure reviewing

### 提交与补充说明

单击 **提交作答**，系统分别核对答案和理由。理由完整时，系统直接判定。缺少关键理由时，系统会追问并等待补充。

系统保留首次作答，补充理由单独记录。答案和理由均通过核对时，本次任务通过。答案正确但理由错误时，本次任务判为未通过。

### 查看结果

核对完成后，查看结果与点评，再继续下一题。完成本轮练习后，可查看题目、答案和用时。

### 继续、退出与重试

完成判定后，单击 **下一题**；最后一题显示 **结束复习**。使用 **退出复习** 返回工作区。

出现补充理由提示时，在当前题继续说明。出现服务错误时，先检查连接，再按页面提示重试。等待回复期间，避免重复提交同一份答案。

> 智能核对结果属于 AI 建议。“暂时无法可靠判断”或“待核对”表示本题尚未完成。请核对题干、参考答案和理由，再补充说明或重试。失败和待核对状态均不计入答错次数。

## AI 学习助手 {#assistant}

### 发起学习对话

在应用首页单击 **开始复习**，输入学习问题。例如，可输入“请用一个例子讲解虚拟语气”。也可先选择参考知识库，再输入问题。

助手回复会逐步显示。聊天记录按账号保存在当前浏览器中。支持新建、切换、重命名和删除对话。单击记录旁的 **⋯** 或向左拖动，可展开操作。

关闭聊天面板、切换聊天或切换题目时，已经发出的对话会继续在后台执行，结果回到原来的聊天或题目中。可通过后台任务入口查看进度和打开结果。

发送请求、接收回复和发生异常时会保存记录。异常不会清掉已收到的部分回复；重试前会保留一份 **上次回复快照**。关闭浏览器或刷新页面会将未完成的回复保存为中断状态，重新打开后可查看并重试。

新对话先使用第一条消息作为临时标题。成功完成 3 轮问答后，助手会根据对话内容自动生成一次简短标题，之后不再自动更改。手动命名的对话会保留名称；生成失败时保留原名，并在下一轮成功回复后重试，不影响继续聊天。

:::figure assistant

### 设置本次提问的参考范围

单击输入框旁的 **选择知识库**，添加需要参考的资料。已选知识库会显示在 **提问范围** 中。

单击知识库名称旁的 **×**，可从本次范围移除。需要增加或更新资料时，打开 **知识库管理**。资料入库完成后，再选择它提问。

:::figure assistant-scope

### 管理聊天记录与重试回复

新建对话后，可输入新的学习目标。切换历史记录，可继续此前的问题。重命名用于整理列表，删除前可先确认记录内容。

按 **Enter** 发送，按 **Shift + Enter** 换行。发送失败时，使用回复区域的 **重试**。助手返回的题目链接可用于打开对应错题。

### 讨论当前题目

打开题目，展开复习建议卡片，单击 **学习此题知识点**。助手根据当前题目提供讲解。可继续询问条件、步骤或解题方法。

单题对话支持继续提问、查看历史和清空。使用前，请保存题目修改，确保助手读取最新内容。

当前题目存在未保存修改时，相关学习操作可能暂不可用。先按 **Ctrl + S**，再重新打开学习入口。

### 安排关联复习

单击 **让助手安排复习**，系统从当前错题本中选择已有题目。预览包含当前题，并显示选题理由、历史记录和预计用时。

核对预览后，单击 **确认并进入复习**。应用按预览顺序进入练习。

“关联尚未确认”表示该题来自检索结果，关联仍需核对。其他关联说明附有原文引文，也应结合题目内容判断。

> 题目修改、删除或组题方案过期后，需要重新组题。关联复习仅选择已有题目。

## 知识库与学习资料 {#knowledge}

### 创建与选择知识库

从学习助手打开 **知识库管理**。可新建知识库，编辑名称和简介，以及搜索、归档或删除知识库。提问前，使用 **选择知识库** 设置参考范围。

### 导入资料文件

在 **导入学习资料** 中单击 **导入文件**，选择 Markdown（轻量级标记语言）或 PDF 文件。每个文件创建一个服务端知识库。入库完成后，可检索资料内容。

导入时会根据资料内容自动生成简短简介。错题本入库后，也会结合已入库的错题概括知识库内容。手动填写的简介会保留；简介生成失败不影响资料或错题入库。

Markdown 文件须使用 UTF-8（字符编码），单个文件不超过 5 MB（兆字节）。PDF 单个文件不超过 100 MB，最多 300 页。资料导入保留全文、表格、公式和图片。

### 更新错题检索索引

在 **管理知识库 → 错题本入库** 中，选择目标知识库和来源错题本，再单击 **执行入库**。入库任务读取服务器中已保存的题目。

在知识库卡片上单击 **查看错题**，可搜索、翻页浏览已入库题目，并展开题干、公共材料、学生答案和参考解析。显示的是入库时保存的内容。

单击题目旁的 **从知识库移除** 并确认，可只移除该知识库中的题目和检索索引，源错题及其他知识库会保留。再次执行来源错题本入库时，该题会重新导入。来源错题本正在入库时，请等待完成后再移除。

:::figure knowledge

题目新增、修改或删除后，需再次执行入库，以更新索引。页面显示新增、更新、删除、跳过和失败数量。存在失败项时，请检查后重新执行。

单击 **移除该错题本索引**，可移除对应的检索索引。

### 区分题目、资料与检索索引

| 内容 | 保存位置与用途 | 修改后的操作 |
| --- | --- | --- |
| 错题与答案 | 错题本中，用于编辑和复习 | 保存题目后，可重新执行入库 |
| 讲义或参考资料 | 知识库中，用于检索与提问 | 根据资料版本重新导入 |
| 错题本检索索引 | 目标知识库中，用于查找已入库题目 | 新增、修改或删除题目后手动更新 |

移除错题本索引用于调整检索范围。错题本中的原题仍可编辑和复习。文件夹移动完成后，需要更新检索内容时，再手动执行入库。

### 查看任务状态

资料导入和索引任务支持后台运行。可在任务中心或知识库中查看状态。确认入库完成后，再执行检索。

解析、存储或连接失败时，请查看具体提示。解决问题后，再重试任务。

导入过程中，可使用 **取消本次导入**。若显示 **重试清理**，请按提示完成清理，再重新导入。

### 归档、恢复与删除知识库

不常用的知识库可先归档。在管理页面勾选 **显示已归档**，可找到已归档资料。单击 **恢复** 并确认，可重新使用。

删除时，先核对名称，再单击 **确认删除**。资料及检索索引会被删除，源错题和聊天记录保留。显示 **重试删除** 时，说明上次删除尚未完成。

## 单词与语言学习 {#vocabulary}

### 启用插件

在错题本侧边栏单击 **添加功能**，选择语言学习并安装。安装后，从插件入口进入词库和训练界面。

### 创建与导入词库

可新建词库并逐个添加单词。也可导入 Anki（记忆卡片软件）单词包，核对字段对应关系后确认导入。

已有单词表可通过 **粘贴表格导入** 录入。导入前，设置目标词库、字段和标签。

单词可记录音标、释义、例句、翻译和注释。**全部单词** 页面支持搜索、标签筛选、编辑和删除。

### 粘贴表格与知识卡片

在 **粘贴表格导入单词** 中，选择新建词库或追加到已有词库。选择新建时，还需要填写名称。

可输入对齐表格，也可使用“术语、释义、例句、解析”的卡片格式。例如：

```text
progress
释义：进步；进展
例句：We make progress every day.
解析：表示逐渐取得的进展。
```

原文的字段名称不同时，可修改 **释义字段别名**、**例句字段别名** 和 **解析字段别名**。

本次导入可统一添加标签，多个标签用逗号分隔。核对有效单词数和前几条预览，再单击 **一键导入**。词性会自动保存为标签。

### 管理单个词条与搜索

单击 **新增单词**，填写单词及释义，并按需要补充音标、例句、译文和注释。

打开 **全部单词**，可按单词、释义、音标或标签搜索。选择标签可进一步缩小范围。单击对应词条的 **编辑** 或 **删除**，管理该条记录。

### 今日计划与单词预览

先选择词库，再设置每日学习量。今日计划显示总量、新学和到期数量，并分别显示各训练模式的完成进度。

展开 **预览今日单词**，单击某个词条可查看内容。未来待复习总览显示后续到期分布。

:::figure vocabulary

### 学习、拼写与释义训练

| 入口 | 操作 |
| --- | --- |
| 开始今日复习 | 查看词条，单击显示翻译和注释，再进入下一词 |
| 今日中 → 英 | 根据中文释义输入英语单词 |
| 今日英 → 中 | 根据英语单词输入中文意思 |

单击读音按钮，可播放发音。输入答案后，单击 **检查答案** 或按 **Enter**。核对你的答案、正确答案和详解后，再按 **Enter** 进入下一题。

今日复习循环使用当日固定计划。中英互译训练还会加入后续需要重练的词条。完成一次训练后，可返回词库查看进度。

### 调整复习曲线

单击 **复习曲线**，设置连续答对各阶段的间隔天数，以及答错后再次出现的分钟数。单击 **保存设置** 生效。

连续答对会逐级延长间隔，达到最后一级后保持该间隔。后续到期词会加入中英互译训练。

### 删除词库

词库工具栏的垃圾桶按钮用于删除当前词库。确认前，请核对名称和范围。

删除会移除该词库的原始单词包、词条、音频和学习进度。已归档到错题本的错题保留。

## 统计与学习记录 {#statistics}

### 查看总体统计

在工作区单击 **统计**，查看当前错题本的总错题数、待复习数、今日已复习数和累计复习次数。

学科分布显示题目构成。近 7 天复习图显示学习活动。掌握程度分布显示题目的复习状态。

:::figure statistics

### 查看复习历史

在复习历史中选择 **到期复习** 或 **自由复习**。单击记录，可查看完成题量、总用时和逐题作答详情。

### 查看单题记录

打开题目，可查看复习次数、答错次数和学习记录。

复习次数按完成记录累计。答错次数只统计明确判为错误的作答。待核对、等待补充理由和服务失败均不计入答错次数。掌握程度与作答对错分别记录。

### 展开单题的复习明细

在题目的复习建议卡片中，展开 **查看复习记录**。时间线显示日期、掌握评级，以及答对、答错或未判定状态。

未判定的记录可用于回顾学习过程。判断错误率时，应结合明确完成的作答结果。

## 备份与数据迁移 {#backup}

### 导出归档

选择 **更多 → 导出归档**，保存 `.ctb` 文件。网页版通过浏览器下载。桌面版通过原生保存对话框选择位置。

归档用于恢复和迁移数据。批量导入、删除或更换设备前，建议先导出归档，并确认文件已保存。

:::figure backup

### 导入归档

选择 **更多 → 导入归档**，支持 `.ctb` 和 `.zip` 文件。按提示选择保留或重置复习进度，再选择文件。

完整归档会恢复所含错题本、题组和图片。旧版归档导入当前错题本。相同 ID（标识符）的题目会覆盖现有记录，导入前请备份当前数据。

### 导出 PDF

选择 **更多 → 导出 PDF（打印）**。在打印窗口中，选择保存为 PDF。导出内容按学科分组，包含题目和已有答案。

### 选择整本备份或部分导出

| 需要的结果 | 使用入口 |
| --- | --- |
| 恢复或迁移完整学习数据 | 更多 → 导出归档 |
| 提取勾选的部分题目 | 已选菜单 → 批量导出 |
| 阅读或打印题目 | 更多 → 导出 PDF（打印） |
| 仅整理同一本内的存放位置 | [文件夹移动](#folders) |

批量导出的 JSON 与 `.ctb` 归档格式不同。恢复数据时，请使用导入入口支持的文件类型。

### 保存位置与备份范围

网页版使用浏览器本地存储，并通过后端服务保存数据。桌面版另使用本地数据目录。不同账号的数据分别管理。

> 归档用于恢复数据，PDF 用于阅读和打印。请另行保留知识库资料的原文件。知识库资料和检索索引的备份范围，以实际归档内容为准。

## 外观与编辑偏好 {#settings}

### 主题、字号与默认错题本

打开侧边栏的 **设置**，切换深色模式或调整正文大小。

默认笔记本可指定一本错题本，也可设置为恢复上次打开的笔记本。设置在下次进入应用时生效。

:::figure settings

### 保存方式

开启 **自动保存** 后，应用在停止输入后保存修改。关闭后，请按 **Ctrl + S** 保存。

编辑快照用于意外恢复。完成关键修改后，也可主动保存。

### 复习参数

展开 **复习设置**，修改首次复习间隔、未掌握与已掌握知识点的间隔，以及增长系数和最大间隔。修改后，单击 **保存复习设置**。

上述参数用于复习间隔设置。智能判卷结果与掌握评级分别记录。一次判卷结果本身不会改变掌握等级。

### 编辑布局

拖动侧边栏边缘，可调整宽度。单击 **调整布局**，可调整板块位置和尺寸。完成后锁定布局，也可恢复默认布局。

单击 **收起侧栏**，可扩大工作区。侧栏中的 **收起筛选面板** 用于缩小分类区域。单击学科、标签、来源等标题，可收起对应分类列表。

拖动筛选区与题目列表之间的分隔条，可重新分配上下空间。需要查找较长题名时，也可先加宽侧栏。

**更改保存目录** 仅桌面版可用。帮助区域提供官网、使用文档和快捷键入口。

在 macOS（苹果电脑操作系统）中，带 Ctrl 的操作通常可使用 Command。快捷键与浏览器或系统冲突时，请使用对应页面按钮。

## 常见问题 {#faq}

### 为什么文件夹的移入按钮没有显示？

先选中至少一道题，再将鼠标移到目标文件夹行。向下箭头按钮会显示在文件夹右侧，提示包含题数和目标名称。

### 为什么全选后包含了其他文件夹的题目？

顶部全选框选择全部符合筛选条件的题目。收起文件夹不会排除其中的题目。仅移动一夹内容时，请按[文件夹迁移步骤](#folders)在原文件夹内选择。

### 删除文件夹会同时删除题目吗？

删除文件夹后，其中的题目移到 **未归档**。需要删除题目时，请另外选择题目并执行删除。

### 为什么导入照片后仍是图片？

若选择 **仅插入图片**，结果会保留为图片。需要可编辑文字时，请再次导入，核对识别结果后选择 **插入文字**。

### 如何同时保留识别文字与原图？

在 **图片转文字** 窗口勾选 **同时保留原图**，再单击 **插入文字**。操作步骤见[照片与截图转文字](#image-text)。

### 为什么图片大小选项不可用？

先单击编辑区中的图片，再打开 **调整图片大小**。仅将光标放在图片旁边，不会选中图片。

### 为什么新建或移动的题目没有出现在列表中？

检查搜索词、学科、来源、标签和掌握程度。恢复完整筛选范围后，再展开目标文件夹。若题目列表加载失败，请使用 **重试加载**。

### 如何显示正确答案？

使用答案区域的显示按钮，或按 **Ctrl + R** 切换。复习时，先独立作答，再按提示核对答案。

### 到期题数为 0 时如何练习？

将复习范围切换为 **自由练习**，再从全部题目中选择。

### 何时需要补充解题理由？

系统需要结合答案和理由判断作答。缺少关键理由时，请补充步骤、概念或条件。理由可使用自然语言、公式或演算。首次作答已解释清楚时，可直接进入判定。

### “待核对”是否计入答错次数？

“待核对”表示系统尚未完成判定，不计入完成次数或答错次数。请核对题目和参考答案，补充理由，或在恢复连接后重试。

### 如何处理识别错误？

在预览中修正结果，再确认导入。重点检查公式、数字、跨页内容、选项和材料归属。图形题应保留原图。服务失败时，请保留原文件并按提示重试。

### 修改题目后如何更新检索内容？

先保存题目，再进入 **知识库管理 → 错题本入库**，手动执行更新。索引完成后，选择对应知识库提问。

### 切换题目时如何处理保存提示？

存在未保存修改时，可选择保存后切换、放弃修改或取消切换。也可在设置中开启自动保存。

### 更换设备前如何备份？

导出归档并确认文件已保存，同时保留学习资料的原文件。浏览器缓存之外，应另行保存备份文件。退出账号时，请使用 **退出登录**。

### 网页版与桌面版有何区别？

网页版通过浏览器访问。桌面版另提供桌面截图、本地目录和原生文件操作。下载页根据实际安装包发布状态提供链接。

### 阅读文档是否需要登录？

官网、使用文档和下载页可直接访问。进入应用管理学习数据时，需要登录。
